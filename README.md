# gesn-search

Поиск кода работы ГЭСН (государственные элементные сметные нормы) по описанию в свободной форме: «покрасить стены в квартире» → `15-04-005-01`.

Сравниваются четыре подхода:
1. BM25 с лемматизацией (`pymorphy3`) — baseline.
2. Готовая модель эмбеддингов `intfloat/multilingual-e5-base`.
3. Та же модель, дообученная на синтетических парах «запрос ↔ норма».
4. Гибриды BM25 + dense через Reciprocal Rank Fusion.

> 🚧 В работе: разбор ошибок и демо. План — в [PLAN.md](PLAN.md).

## Результаты

Ручной тест: 150 запросов, написанных человеком без сметного опыта; у 138 есть ответ в выбранных сборниках. В скобках — 95% бутстреп-доверительный интервал. Recall@k — доля запросов, где хотя бы одна правильная норма попала в top-k.

**Точный код нормы**

| Подход | R@1 | R@5 | R@10 | MRR@10 |
|---|---|---|---|---|
| BM25 | 0.225 [0.15–0.30] | 0.413 [0.33–0.49] | 0.442 [0.36–0.53] | 0.294 [0.23–0.36] |
| e5 (готовая) | 0.370 [0.29–0.46] | 0.565 [0.49–0.65] | 0.645 [0.57–0.72] | 0.456 [0.38–0.53] |
| BM25 + e5 | 0.304 [0.23–0.38] | 0.522 [0.43–0.60] | 0.623 [0.54–0.70] | 0.402 [0.33–0.47] |
| **e5 дообученная** | **0.514** [0.43–0.60] | **0.674** [0.60–0.75] | **0.768** [0.70–0.84] | **0.589** [0.52–0.67] |
| BM25 + e5 дообученная | 0.384 [0.30–0.46] | 0.616 [0.54–0.70] | 0.688 [0.61–0.76] | 0.482 [0.41–0.55] |

**Правильная таблица** (код без последнего сегмента, например `15-04-005`)

| Подход | R@1 | R@5 | R@10 | MRR@10 |
|---|---|---|---|---|
| BM25 | 0.246 | 0.507 | 0.609 | 0.366 |
| e5 (готовая) | 0.406 | 0.681 | 0.746 | 0.522 |
| BM25 + e5 | 0.355 | 0.674 | 0.783 | 0.493 |

Полные таблицы: [results/test.md](results/test.md), синтетический dev (532 запроса к отложенным нормам): [results/dev.md](results/dev.md).

**Выводы**
- Дообучение на ~10 тыс. синтетических пар подняло точное попадание с первой позиции с 37% до 51%, а правильную таблицу в top-10 — с 75% до 91%.
- BM25 слаб даже с лемматизацией: люди пишут «покрасить», «залить», «постелить», а нормы — «окраска», «устройство», «покрытие».
- Гибрид с BM25 при равных весах только ухудшает dense-модель: слабый лексический сигнал размывает верх выдачи.

## Как устроено

| Этап | Где | Что |
|---|---|---|
| Справочник | `gesn.parse` | ФСНБ-2022 (XML) → 2940 норм из 6 сборников |
| Тест | `data/test/` | 150 запросов вручную, разметка по пулу кандидатов — см. [LABELING.md](data/test/LABELING.md) |
| Синтетика | `gesn.generate` | Qwen2.5-7B-Instruct пишет по 5 запросов к норме в разных стилях |
| Очистка | `gesn.synth` | фильтры копий названия и неоднозначных дублей; трудный негатив — соседняя норма той же таблицы |
| Дообучение | `gesn.train` | `CachedMultipleNegativesRankingLoss`, батч 128, 1 эпоха, ~6 мин на T4 |
| Оценка | `gesn.evaluate` | Recall@k, MRR@10 на уровне кода и таблицы, бутстреп-CI |

Генерация, обучение и оценка запускаются одним ноутбуком на бесплатном GPU Kaggle: [notebooks/kaggle_pipeline.ipynb](notebooks/kaggle_pipeline.ipynb) (сохранён с выводом последнего прогона).

Тест и обучающие данные получены из разных источников: запросы теста написал человек, обучающие — открытая LLM; нормы dev-набора при обучении не использовались.

## Данные

ФСНБ-2022 в формате открытых данных (XML) с [ФГИС ЦС](https://fgiscs.minstroyrf.ru/frsn/fsnb). В скоупе 6 сборников: 06, 08, 10, 11, 12, 15 — 2940 норм, 625 таблиц.
